# Addons

### What are these addons?

Addons are optional features not included in standard KGenerators.

You can **install** them simply by putting as **standard plugins**.

**Configs** (if there are any) will be generated in **KGenerators folder**.

**Logs** will be provided in **KGenerators folder**

### **Where to get addons?**

> [!NOTE]
> The original addons were published on upstream's CI (`ci.codemc.io/job/Kryniowesegryderiusz`),
> which no longer has them, and their source code was never public. They are not available for
> KGenerators Regenerated.
