# DecentHolograms

### What is included in DecentHolograms support?

* DecentHolograms support for generator's holograms

### Configuration

Holograms are shown above generators that have `hologram: true` in `generators.yml`. Their lines are set in `holograms.remaining-time` in your language file.

DecentHolograms is only used if [FancyHolograms](fancyholograms.md) is not installed.

### Compatibility

Built against DecentHolograms 2.10.2.
