# CMI

### What is included in CMI support?

* CMI holograms for generator's holograms

### Configuration

Holograms are shown above generators that have `hologram: true` in `generators.yml`. Their lines are set in `holograms.remaining-time` in your language file.

CMI holograms are only used if neither [FancyHolograms](fancyholograms.md) nor [DecentHolograms](decentholograms.md) is installed.

### Compatibility

Built against CMI API 9.8.6.4 with CMILib 1.6.0.4.
