# Lands

### What is included in Lands support?

* Generators will be protected in lands:
  * Mining - block break role permission
  * Placing - block place role permission
  * Pick up / interact - general interact role permission

Players with `kgenerators.bypass.lands` ignore this protection.

### Compatibility

Built against Lands API 7.0.2. Lands itself is now at 9.x, and its API may have changed since.
