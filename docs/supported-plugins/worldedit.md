# WorldEdit

### What is included in WorldEdit support?

* Spawning generators in every block of your WorldEdit selection
* Removing all generators in your WorldEdit selection

### Commands

* `/kgenerators spawn worldedit <generator_ID> [owner]` - permission `kgenerators.spawn`
* `/kgenerators remove worldedit` - permission `kgenerators.remove`

See [Commands & Permissions](../commands-and-permissions.md).

### Compatibility

Built against WorldEdit 7.2.20. WorldEdit 7.3 and later need Java 21.
