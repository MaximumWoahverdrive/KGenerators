# PlaceholderAPI

### Where can placeholders be used?

* All language files

### What placeholders are included?

* `%kgenerators_generators_placed_all%` Returns amount of all placed generators
* `%kgenerators_generators_placed_<generatorID>%` Returns amount of placed specific generators
* `%kgenerators_limits_limit_<limitID>%` Returns user limit
* `%kgenerators_limits_placed_<limitID>%` Returns user limit already used
* `%kgenerators_limits_left_<limitID>%` Returns used limit left
