# FactionsUUID

### What is included in FactionsUUID support?

* Generators will be protected inside claims

Players with `kgenerators.bypass.factionsuuid` ignore this protection.

### Compatibility

Built against FactionsUUID 1.6.9.5-U0.6.40. FactionsUUID 0.7.x and later dropped Minecraft versions below 1.20.4, and 4.x is a rewrite whose API may differ, so the hook may not work with 4.x.
